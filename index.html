How to Add or Edit Chapters

  1. Open index.html in a text editor.
  2. Copy a <section> block and change the ID, title, subtitle, image, and paragraph.
  3. Add a link in the sidebar with data-target matching the section ID.
  4. Add your images into the assets/ folder.
