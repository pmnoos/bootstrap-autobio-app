## ✍️ How to Add or Edit Chapters
1. Open `index.html` in a text editor.
2. Duplicate one of the `<section>` blocks for a new chapter.
3. Update the section ID, heading, subtitle, image source, and text.
4. Add a new link in the sidebar with the same `data-target`.
